---
title: 貨幣概念
description: 了解 Trader API 回應中的基礎、報價、結算及顯示貨幣。
---

Trader API 回應使用多種貨幣角色。應由相關帳戶或合約欄位讀取角色，不要由 contract code 推斷。

## 基礎及報價貨幣

外匯合約包含基礎貨幣及報價貨幣。報價表示購買一單位基礎貨幣需要多少報價貨幣。

以 `EURUSD` 為例：

- `EUR` 是基礎貨幣。
- `USD` 是報價貨幣，亦稱相對貨幣。
- 價格 `1.0850` 表示一歐元價值 1.0850 美元。

WebProxy 在合約設定中以 `baseCurr` 及 `counterCurr` 回傳這些值。貴金屬、商品、CFD 及加密資產等其他產品類別也使用相同欄位識別與合約相關的貨幣。

## 結算貨幣

結算貨幣用於帳戶餘額及結算計算。WebProxy 在帳戶資料回應中以 `settleCurr` 回傳。

結算貨幣可以與合約的基礎及報價貨幣不同。不要假設所有帳戶都以 USD 結算，亦不要由 contract code 推斷結算貨幣。

## 顯示貨幣

顯示貨幣控制 WebProxy 如何在受支援的帳戶及報表回應中顯示金額。WebProxy 以 `displayCurr` 回傳。

顯示貨幣只是顯示設定，不會改變 contract code、掛單數量或執行貨幣。

## 保證金

FxServer 以平台系統貨幣計算保證金。計算方法及換算輸入值由伺服器管理，不屬於公開整合合約。

將平台回傳的保證金數值視為權威結果。應用程式不應嘗試用合約價格或貨幣欄位重現計算。

## 換算方式

某些 WebProxy 帳戶回應包含 `convRate` 及 `convOp`，用於換算顯示值。只按該端點回應 schema 的說明使用這些欄位。

所有由伺服器計算的金融數值都應視為權威結果。不要從貨幣對名稱或公開 API 欄位推斷保證金或結算計算方式。
