title: 即時價格串流
description: 使用環境價格串流提供的 bid、ask 及 priceTag。
---

目標環境設定的價格串流為 Trader 整合提供報價。串流端點、傳輸設定及憑證由整合環境提供。

## 報價欄位

每個報價識別一個市場，並提供 Trader 用戶端使用的價格：

| 欄位 | 用途 |
| --- | --- |
| `market` | 與報價對應的市場或合約識別碼。 |
| `bid` | 交易者賣出時使用的價格。 |
| `ask` | 交易者買入時使用的價格。 |
| `tag` | 報價的不透明識別碼。 |
| `highBid`, `lowBid` | 選填的 bid 側高低值。 |
| `highAsk`, `lowAsk` | 選填的 ask 側高低值。 |

將 `tag` 視為不可解析的值。即使其中一部分像 market code 或時間戳，也不要解析、產生或修改它。

## 在請求中使用報價

市價模式請求不包含串流數值。將 `priceMode` 設為 `1`，並省略 `price` 及 `priceTag`。

報價模式的處理方式：

1. 賣出請求選擇當前 bid；買入請求選擇當前 ask。
2. 將該值以 `price` 傳送。
3. 伺服器端價格驗證已啟用時，將 `priceTag` 格式設為 `${tag};${price}`。
4. 不修改價格或 tag，直接傳送請求。

FxServer 可以拒絕過期、未知或不符合的報價資料。不要無限重試舊 tag，應取得新報價。

## 通訊協定細節

價格串流的訊息框架及數值編碼視傳輸方式而定。使用目標環境提供的用戶端程式庫或通訊協定規格。不要單憑欄位名稱自行實作二進制解析器；位元組順序、訊息長度、數值縮放及選填欄位規則必須與已部署的串流版本一致。
