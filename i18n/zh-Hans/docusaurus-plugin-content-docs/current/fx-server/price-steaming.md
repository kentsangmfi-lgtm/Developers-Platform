---
title: 实时价格数据流
description: 使用环境价格数据流提供的 bid、ask 及 priceTag。
---

目标环境设置的价格数据流为 Trader 集成提供报价。数据流端点、传输设置及凭证由集成环境提供。

## 报价字段

每个报价识别一个市场，并提供 Trader 客户端使用的价格：

| 字段 | 用途 |
| --- | --- |
| `market` | 与报价对应的市场或合约识别码。 |
| `bid` | 交易者卖出时使用的价格。 |
| `ask` | 交易者买入时使用的价格。 |
| `tag` | 报价的不透明识别码。 |
| `highBid`, `lowBid` | 选填的 bid 侧高低值。 |
| `highAsk`, `lowAsk` | 选填的 ask 侧高低值。 |

将 `tag` 视为不可解析的值。即使其中一部分像 market code 或时间戳，也不要解析、生成或修改它。

## 在请求中使用报价

市价模式请求不包含数据流数值。将 `priceMode` 设为 `1`，并省略 `price` 及 `priceTag`。

报价模式的处理方式：

1. 卖出请求选择当前 bid；买入请求选择当前 ask。
2. 将该值以 `price` 传送。
3. 服务器端价格验证已启用时，将 `priceTag` 格式设为 `${tag};${price}`。
4. 不修改价格或 tag，直接传送请求。

FxServer 可以拒绝过期、未知或不符合的报价数据。不要无限重试旧 tag，应获取新报价。

## 通信协议细节

价格数据流的消息框架及数值编码视传输方式而定。使用目标环境提供的客户端库或通信协议规格。不要单凭字段名称自行实现二进制解析器；字节顺序、消息长度、数值缩放及选填字段规则必须与已部署的数据流版本一致。

阅读 [价格概念](../business-logic/price-concept) 了解价格模式行为，并参阅 [REST API 基础](./general-rest-api-information) 处理错误。
