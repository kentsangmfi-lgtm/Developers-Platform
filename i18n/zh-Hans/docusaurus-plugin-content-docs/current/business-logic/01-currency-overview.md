---
title: 货币概念
description: 了解 Trader API 响应中的基础、报价、结算及显示货币。
---

Trader API 响应使用多种货币角色。应由相关账户或合约字段读取角色，不要由 contract code 推断。

## 基础及报价货币

外汇合约包含基础货币及报价货币。报价表示购买一单位基础货币需要多少报价货币。

以 `EURUSD` 为例：

- `EUR` 是基础货币。
- `USD` 是报价货币，亦称相对货币。
- 价格 `1.0850` 表示一欧元价值 1.0850 美元。

WebProxy 在合约设置中以 `baseCurr` 及 `counterCurr` 返回这些值。贵金属、商品、CFD 及加密资产等其他产品类别也使用相同字段识别与合约相关的货币。

## 结算货币

结算货币用于账户余额及结算计算。WebProxy 在账户数据响应中以 `settleCurr` 返回。

结算货币可以与合约的基础及报价货币不同。不要假设所有账户都以 USD 结算，亦不要由 contract code 推断结算货币。

## 显示货币

显示货币控制 WebProxy 如何在受支持的账户及报表响应中显示金额。WebProxy 以 `displayCurr` 返回。

显示货币只是显示设置，不会改变 contract code、挂单数量或执行货币。

## 保证金

FxServer 以平台系统货币计算保证金。计算方法及换算输入值由服务器管理，不属于公开集成合约。

将平台返回的保证金数值视为权威结果。应用程序不应尝试用合约价格或货币字段重现计算。

## 换算方式

某些 WebProxy 账户响应包含 `convRate` 及 `convOp`，用于换算显示值。只按该端点响应 schema 的说明使用这些字段。

所有由服务器计算的金融数值都应视为权威结果。不要从货币对名称或公开 API 字段推断保证金或结算计算方式。
